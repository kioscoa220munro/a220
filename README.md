# A220 - Sistema de Gestión para Kiosco

Sistema completo de gestión de ventas, stock y productos con lector de código de barras integrado.

## 🚀 Características

- 📷 **Lector de código de barras** con cámara (QuaggaJS)
- 🖼️ **Vista previa de productos** con imágenes
- ➕ **Selector de cantidad** con botones + y -
- 📦 **Carrito de compras** en tiempo real
- 📊 **Dashboard** con ventas y alertas de stock
- 🔗 **Sincronización con GitHub** para compartir datos
- 🌙 **Modo oscuro** integrado
- 📱 **Responsive** para PC y celular
